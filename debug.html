Session activity

First physical test

  1. Connect the laptop to the rover's Wi-Fi. Run the live Windows controller launcher.
  2. Place the rover on a clear bench with the wheels safely clear of the surface for the first direction check.
  3. Wait for the rover transport to be ready. Click ARM controls, then hold one direction briefly at the default 0.10 command.
  4. Release, verify neutral, then press STOP. Check forward, reverse and pivot directions before putting it on an open floor.
Software STOP is best effort. Keep access to the rover's power switch. Browser events, Wi-Fi commands and watchdogs are not a physical emergency stop.
The scan planner opens separately from its HTML file.

How the hold control behaves

While a direction is held, the page sends a command every 100 ms. Releasing sends neutral immediately and leaves the controller armed. STOP, Disarm, opposing keys, mixed mouse/keyboard input, window blur, a hidden tab or a connection fault disarms the controls. The server's watchdog clears stale nonzero commands. A fresh ARM is required after a stop or fault.

The server must be opened on http://127.0.0.1:8765 or http://localhost:8765. This page has no external scripts, fonts or network dependencies. It only calls the local server; that server handles rover communication.
